This is a patch release (0.4.2) to fix CRAN check failures caused by a breaking change
in the `PerformanceAnalytics` package. The package was archived on 2026-05-18; this
submission requests reinstatement.

---

## Changes since last CRAN release (0.4.1)

* Fixed unit tests: `PerformanceAnalytics::Return.portfolio()` now returns results for
  the full length of the input return series rather than only from the first specified
  weight date onward. Tests now subset the PerformanceAnalytics output to the dates
  covered by the backtest before comparison.

* Fixed missing `importFrom(ggplot2, scale_linetype_manual)` that caused an ERROR in
  `--run-donttest` examples.

* Documented the `...` argument of `summaryTable()`.

* Added book reference to `Description` field and `URL` field (Chapter 8, Portfolio
  Backtesting, of "Portfolio Optimization: Theory and Application", Cambridge University
  Press, 2025).

---

## R CMD check results

There were no ERRORs or WARNINGs.

There were 3 NOTEs:

1. _"New submission / Package was archived on CRAN"_ — expected; this submission
   requests reinstatement after fixing the reported issues.

2. _"unable to verify current time"_ — NTP issue on the local check machine; not
   reproducible on CRAN infrastructure.

3. _"HTML validation problems"_ — cosmetic `<table>`/`<script>` attribute warnings
   generated by the R documentation renderer; not caused by package code.
